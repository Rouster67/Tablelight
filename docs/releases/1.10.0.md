# Tablelight v1.10.0

Tablelight now has a Windows installer and can check for new stable releases when you open it.
This release also adds the DM version display and concentration reminders.

## Install or upgrade

Download **Tablelight-Setup-1.10.0-x64.exe** and run it. Existing users of the portable ZIP need
this one-time installation to enable in-app updates. Export a party backup first. The installed
app uses the existing `%APPDATA%\Tablelight` save folder, so your characters, portraits, parties,
and libraries stay in place. Uninstalling keeps this saved data.

**Windows compatibility:** This installer is unsigned. Windows may warn about it, and Application
Control or Smart App Control can block installation entirely. If Windows blocks installation,
keep your current Tablelight version until a compatible installer is available.

## What's new

- **Update and restart:** Installed copies check in the background once per launch. A newer stable
  release offers Update and restart or Later. Downloads show progress and can be canceled. Before
  installing, Tablelight verifies the download and saves the latest party. It reopens with the TV
  overlay hidden. Later leaves a small update arrow beside the sidebar version.
- **Update controls:** Setup & help includes Check now and a setting to disable automatic checks.
  Offline launches and failed checks do not interrupt normal play. Checks send no character,
  party, portrait, note, or library content; see [network details](https://github.com/Rouster67/Tablelight/blob/v1.10.0/docs/UPDATES.md).
- **Visible version:** The DM title bar and sidebar show the running application's version.
- **Concentration reminders:** Damage controls show a gently pulsing reminder while concentrating,
  with reduced-motion support. Using a flagged ability starts concentration or asks before replacing
  an existing concentration ability. Cancel spends nothing; Undo restores concentration and costs
  together. Damage does not automatically end concentration or roll a saving throw.
- **Download recovery:** Canceled, stalled, invalid, or unexpectedly redirected downloads fail
  cleanly and allow retry. Redirect loops are limited.

## Release files

- `Tablelight-Setup-1.10.0-x64.exe`: the installer for Windows x64.
- `Tablelight-Setup-1.10.0-x64.exe.blockmap` and `latest.yml`: updater metadata; keep these attached
  to the release. Users do not need to open them.

The installer includes editable application source and license notices. Source runs and unpacked
previews do not enable in-app installation. No update installs just because you close Tablelight.
