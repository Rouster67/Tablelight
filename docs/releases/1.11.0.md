# Tablelight 1.11.0 — Ability details and DM approval

Tablelight now lets players request ability uses from their overlays while the DM reviews and
approves them. This release also expands ability details and adds independent character-only
abilities.

## What's new

- **DM approval queue:** Overlay ability uses reserve the player's action, spell slots, and other
  configured costs until the DM allows or denies the request. Review full ability details,
  minimize requests, open the character, or let the player cancel. DM-console uses remain immediate.
- **Urgent reactions:** Up to three ordinary ability requests can wait across the party.
  Reactions appear first in red and do not count against that limit, while still requiring the
  character's available reaction.
- **History and targeted undo:** Review the five most recent outcomes, reconsider a denied,
  canceled, or expired request, or undo one approved use. Refunds preserve unrelated changes and
  later tracked spending. Related resets or corrections block refunds that are no longer safe.
- **Complete ability details:** Add Reference, Upcast / Upgrades, Trigger, Area, Casting Time,
  School, Attack, Save, On Save, Requirements, and Special text. Details appear consistently in
  DM views, player HUDs, and approval requests. Damage, healing, and effects remain manual.
- **Shared and local copies:** Duplicate a library ability with a numbered name, or create a
  local-only ability for one character. Local copies show a person icon and can use independent
  spell-slot and resource settings. Deleting an assigned library ability now offers editing,
  removal from everyone, or keeping local copies on selected characters.
- **More room on the HUD:** The frame grows taller to keep character information, conditions,
  slots, resources, and Smaller/Larger controls visible. Waiting requests have a separate column
  on the far right. History sits beside the DM sidebar, clear of Add character and Setup & help.

The queue and History clear when Tablelight closes. Approved costs remain saved. Changes that
would invalidate pending requests show a warning before proceeding.

## Install or update

Use **Setup & help → Updates → Check now**, or download and run
[Tablelight-Setup-1.11.0-x64.exe](https://github.com/Rouster67/Tablelight/releases/download/v1.11.0/Tablelight-Setup-1.11.0-x64.exe).
The installer preserves existing Tablelight data. After updating, the DM title bar and sidebar
show **1.11.0**.

**Export a party backup before updating if you may need to return to an older version.** This
release imports older saves and writes save format 9. Earlier releases cannot open the new
format. Characters, libraries, resources, notes, and HUD settings are retained during migration.

The Windows x64 installer remains unsigned. The attached `.exe.blockmap` and `latest.yml` files
support in-app updates; you do not need to open them.
