# Tablelight v1.10.1

This patch fixes updates that could install a second copy of Tablelight in a different folder,
leaving your usual shortcut opening the older version.

## What's fixed

- **Updates stay in the running app's folder.** After installing this patch, future in-app
  updates explicitly use that folder, including custom locations and missing Windows
  installation-path records.
- **Save preservation verified.** The real installer test now checks active and saved players,
  assigned and unused ability and condition libraries, portraits, resources, spell slots,
  concentration, notes, settings, the previous save, and the update-check preference. Saved files
  remain unchanged across installation and test uninstall.

## Install or upgrade

Download **Tablelight-Setup-1.10.1-x64.exe** and run it, or use **Update and restart** in your
installed copy. Export a party backup first. Tablelight continues to use `%APPDATA%\Tablelight`
for saved data; ordinary upgrades and uninstalling retain that folder.

**If 1.10.0 keeps reopening as the old version:** Close every Tablelight window, run this
installer manually, and select the folder used by your usual Tablelight shortcut. Version 1.10.0
does not yet have the folder fix, so this one-time repair may be needed to reach the corrected
version. Then open Tablelight, confirm **1.10.1** in the DM title bar, close it, and reopen the
same shortcut to confirm it still shows **1.10.1**.

Existing portable ZIP users still need a one-time installation to enable in-app updates.

**Windows compatibility:** This installer is unsigned. Windows may warn about it, and Application
Control or Smart App Control can block installation entirely. If Windows blocks installation,
keep your current Tablelight version until a compatible installer is available.

Update checks and downloads send no character, party, portrait, note, or library content. The
installation folder is used locally and is not sent to GitHub. See
[network details](https://github.com/Rouster67/Tablelight/blob/v1.10.1/docs/UPDATES.md).

## Release files

- `Tablelight-Setup-1.10.1-x64.exe`: the installer for Windows x64.
- `Tablelight-Setup-1.10.1-x64.exe.blockmap` and `latest.yml`: updater metadata; keep these attached
  to the release. Users do not need to open them.

The installer includes editable application source and license notices. See the
[tagged source](https://github.com/Rouster67/Tablelight/tree/v1.10.1) and
[changes since 1.10.0](https://github.com/Rouster67/Tablelight/compare/v1.10.0...v1.10.1).
