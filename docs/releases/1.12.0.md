# Tablelight 1.12.0 — Ability icons, class themes, and player messages

Add artwork to your abilities, give each character a class color theme, and send notes to a
selected player's overlay. Existing characters, shared libraries and individual settings carry
forward when you update.

## What's new

- **Custom ability icons:** Upload, replace or remove artwork for spells, actions and features.
  Images appear beside abilities on both screens and in party backups. Shared entries update
  every linked character, including inactive players; character-only copies keep their own art.
  Abilities without artwork keep their familiar symbol and name.
- **Independent class themes:** Choose **Theme** in Create or Edit character. Default preserves
  the existing appearance; all 13 class palettes, including Artificer, recolor the bubble,
  expanded HUD and DM preview. Theme selection is separate from the entered class, player color
  and resource colors, and stays with the character in saves and backups.
- **Messages to players:** Choose an active recipient in the new **Messages** sidebar page.
  Sending shows an unread envelope with no text preview, including on collapsed bubbles.
  Players can open, page, scroll and close their note. The DM can force open, page, scroll,
  close or dismiss it while the overlay remains click-through.
- **Clear message status:** Sent, delivered and opened status identify whether the envelope or
  text has appeared. Each player has one retained message, with confirmation before replacement.
  Cards follow the recipient's theme and orientation while preserving saved HUD settings.

**Opened messages are visible to everyone near the shared TV.** A targeted envelope delays
showing the text; it does not provide a private screen. Closing keeps a message available to
reopen, while dismissing removes it. Hiding the overlay closes exposed text. Removing a player
clears their note, and restarting Tablelight or restoring a backup clears all messages and drafts.
Messages are excluded from saved parties, backups and gameplay Undo.

## Ability image limits

Use PNG, JPEG or static WebP files up to **5 MiB**, with neither edge over **4,096 pixels**.
Tablelight preserves the complete image and proportions, fitting it within **256 × 256 pixels**
without cropping or enlarging small artwork. Converted PNGs may use up to **300 KiB each**, with
an **8 MiB** total ability-image budget. Shared images count once; each independent local copy
counts separately. Animated and damaged images are rejected without replacing existing artwork.

## Install or update

Use **Setup & help → Updates → Check now**, or download **Tablelight-Setup-1.12.0-x64.exe** from
this release and run it. The installer preserves existing saved data and updates the same
installation folder. After updating, the DM title bar and sidebar show **1.12.0**.

**Keep an exported backup from before updating if you may need to return to an older version.**
This release imports save formats 1–9 and writes format 10. Tablelight 1.11.0 and earlier cannot
open format 10. Manual ability details, shared and local abilities, both libraries, resources,
notes, inactive characters, and each player's HUD choices are preserved during migration.

The Windows x64 installer remains unsigned. The attached `.exe.blockmap` and `latest.yml` files
support in-app updates; you do not need to open them.
