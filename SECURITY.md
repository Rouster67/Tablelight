# Security

Tablelight loads local application files with context isolation, Electron's renderer sandbox, and Node integration disabled in renderers. Navigation and popups are denied. The UI's Content Security Policy blocks external connections. Privileged operations require the DM window as sender; the overlay uses a narrower command channel.

Installed copies can make optional release-check and installer-download requests from the main process. Update commands require the DM window; renderers cannot supply a URL, download path, executable, or feed. The transport permits only the official repository and GitHub release-asset hosts over HTTPS, strips rollout identifiers and credentials, and uses a separate network session. The release-page command opens one fixed official URL in the default browser. See [updates and network use](docs/UPDATES.md) for the full request and privacy explanation.

The app is a local tracker, not a rules-content downloader. Treat imported party backups and portraits as untrusted data. Keep validation and text escaping in place. A backup can contain private notes and portraits: use synthetic data for public bug reports.

When this repository is published, report vulnerabilities through GitHub's **Security → Report a vulnerability** if private reporting is enabled. If that option is absent, open an issue requesting a private reporting channel without including exploit details or personal data. The maintainer should enable private vulnerability reporting before inviting public security reports.

Only the current application release is maintained. Keep Electron and the updater dependencies updated and run the tests after changes. NSIS installers are currently unsigned. Updates verify a SHA-512 digest from the release metadata, but unsigned packages do not independently verify the publisher; GitHub and the maintainer's release account remain part of the trust boundary. Keep normal signature verification enabled when configuring code signing in the future. Download releases from the project owner's repository and retain a party backup when upgrading. No automatic installation occurs without Update and restart, and failed saving prevents that restart.
